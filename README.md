# Doom Scroll Cool Down

Doom Scroll Cool Down is a web app designed to help users take a mindful break from addictive, algorithm-driven platforms like TikTok, Instagram Reels, or YouTube Shorts. The app uses Google’s Gemini AI to generate calming and personalized "cool-down" videos that encourage users to pause, breathe, and regain control of their attention.

The project aims to address digital fatigue by offering an alternative to endless scrolling—content that centers your focus and promotes well-being.

# Technologies Used
* ReactJS – Frontend framework for building the user interface. Allows us to easily create the website interface and mobile app interface.
* Google Gemini API – For generating recomemnded cool down videos based on the personalized content the user consumes.
* HTML/CSS – Layout and styling.
* mJavaScript/TypeScript – Core logic and application behavior.
